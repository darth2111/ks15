# Гайды по охоте на медведя

Красивая версия с оглавлением и картинками: **https://darth2111.github.io/ks15/guides/**

Каждый гайд лежит в своей папке: `guide.md` (текст с картинками, читается и на GitHub) и `index.html` (то же с оформлением; картинки в папке `images`).

| Гайд | Для кого |
|---|---|
| [01. Памятка](01-pamyatka/guide.md) | Короткая справка: что нажать, кого поставить, что прокачать. Без формул и примеров. |
| [02. Простыми словами](02-prostymi-slovami/guide.md) | Те же правила с объяснением «почему так», картинками и таблицами. Без формул и сложных терминов. |
| [03. Почему так](03-pochemu-tak/guide.md) | Немного школьной математики: откуда берутся цифры и правила. |
| [04. Математика](04-matematika/guide.md) | Полные формулы, выводы и задачи с решениями. Не выше девятого класса. |

Читайте по порядку: если не хватило памятки, откройте «Простыми словами», затем «Почему так» и «Математику».
