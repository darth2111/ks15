# Гайды по охоте на медведя

Каждый гайд лежит в своей папке: `guide.md` (текст, читается и на GitHub) и `index.html` (то же с оформлением, открывается в браузере; картинки в папке `images`).

| Гайд | Для кого |
|---|---|
| [01. Памятка](01-pamyatka/guide.md) | Короткая справка: что нажать, кого поставить, что прокачать. Без формул и примеров. |
| [02. Простыми словами](02-prostymi-slovami/guide.md) | Те же правила с объяснением «почему так», картинками и таблицами. Без формул и сложных терминов. |

Читайте по порядку: если не хватило памятки, откройте «Простыми словами».
